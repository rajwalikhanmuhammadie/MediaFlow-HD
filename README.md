MediaFlow HD
MediaFlow HD is a modern and powerful social media video downloader application built using Google AI Studio and yt-dlp. It allows users to download high-resolution videos and audio from various platforms efficiently.
Features
Fast video and audio downloading using advanced extraction tools.
Supports high resolutions (1080p, 4K, etc.) with automatic stream merging via FFmpeg.
Clean and responsive user interface for seamless media management.
Integrated AI features for enhanced processing and automated workflows.
Environment Variables
Make sure to configure your environment variables in .env based on .env.example:
GEMINI_API_KEY
APP_URL
